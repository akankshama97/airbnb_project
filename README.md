# 🏠 Airbnb Clone
A full-stack Airbnb Clone web application that allows users to explore properties, list accommodations, and book stays. The project is designed to provide a modern, responsive, and user-friendly experience similar to Airbnb.

## 📌 Features
- 🔐 User Authentication (Login & Signup)
- 🏡 Property Listing
- 🔍 Search & Filter Properties
- 📍 Property Details Page
- ❤️ Wishlist (Optional)
- 📅 Booking System
- 📱 Fully Responsive Design
- 🌙 Clean & Modern UI

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap / Tailwind CSS
- React.js (if used)

### Backend
- Node.js
- Express.js
### Database
- MongoDB

### Authentication
- JWT
- bcrypt

### Tools
- Git
- GitHub
- VS Code
- Postman

### Clone Repository
git clone https://github.com/akankshama97/airbnb-clone.git

### Navigate to Project
cd airbnb-clone

### Install Dependencies
npm install
npm install express
npm instal express-session
npm install mongodb
npm install nodemon

### Start Development Server
npm start
npm run dev

## ⚙️ Environment Variables
Create a `.env` file in the root directory.
PORT=3012
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
